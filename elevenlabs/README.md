# Sinch to ElevenLabs Conversational AI Bridge

This project provides a real-time bridge between a [Sinch](https://www.sinch.com/) voice call and an [ElevenLabs](https://elevenlabs.io/) conversational AI agent. It allows a user on a phone call to have a spoken conversation with an AI agent.

The system consists of two main components:
*   **`bridge.py`**: A WebSocket server that acts as the central bridge. It receives the audio stream from Sinch, forwards it to the ElevenLabs Conversational AI API, and sends the AI's audio response back to Sinch.
*   **`stream.py`**: A client script that uses the Sinch Voice API to initiate an outbound call and connect it to the `bridge.py` WebSocket server.

## How It Works

1.  The `stream.py` script is executed. It sends a request to the Sinch API to start a new call.
2.  Sinch dials the specified destination phone number.
3.  When the call answered, Sinch establishes a WebSocket connection to the `bridge.py` server.
4.  The `bridge.py` server accepts the connection from Sinch and, in turn, opens a WebSocket connection to the ElevenLabs Conversational AI API.
5.  The bridge now relays audio in real-time:
    *   Audio from the user (via the Sinch stream) is sent to ElevenLabs.
    *   Audio generated by the ElevenLabs AI agent is sent back to the user (via the Sinch stream).
    *   Interruption event received for the ElevenLabs AI agent triggers sending a "clear" command to Sinch.

## Prerequisites

*   Python 3.x
*   A Sinch account with a provisioned phone number.
*   An ElevenLabs account with an API key and a configured Conversational AI agent.

## Setup

1.  **Clone the repository or download the files.**

2.  **Install dependencies:**
    
    ```bash
    pip3 install -r requirements.txt
    ```

3.  **Configure Environment Variables:**
    Copy the example environment file 
    ```bash
	cp .env.example .env
    ```
	Edit .env and fill in your credentials

    ```env
	# ── Server ────────────────────────────────────────────────────────────────────
	PORT=8765
	
	# Seconds to wait for the Sinch ConnectRequest before dropping the connection
	CONNECT_TIMEOUT_SECONDS=10
	
	# Log level: DEBUG | INFO | WARNING | ERROR
	LOG_LEVEL=INFO
	
	# ── ElevenLabs ────────────────────────────────────────────────────────────────
	ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
	ELEVENLABS_AGENT_ID=your_elevenlabs_agent_id_here
	
	# ── Sinch Voice V2 ────────────────────────────────────────────────────────────
	PROJECT_ID=your_sinch_voice_project_id_here
	KEY_ID=your_sinch_voice_key_id_here
	KEY_SECRET=your_sinch_voice_key_secret_here
	SINCH_NUMBER=your_sinch_voice_number_here
	
	# ── Destination ───────────────────────────────────────────────────────────────
	DESTINATION_NUMBER=the_number_you_want_to_call
	
	# ── Ngrok ─────────────────────────────────────────────────────────────────────
	WS_URL=your_websokcet_url
    ```

## Usage

1.  **Start the Bridge Server:**
    Run the `bridge.py` script. It will listen for incoming WebSocket connections from Sinch.
    ```bash
    python3 bridge.py
    ```
    *(Note: Ensure that the `WS_URL` in your `.env` file is publicly accessible and points to the machine and port where this script is running.)*

2.  **Initiate the Call:**
    In a separate terminal, run the `stream.py` script to place the call.
    ```bash
    python3 stream.py
    ```
    This will trigger the Sinch API to call the `DESTINATION_NUMBER` and connect the audio to your bridge server.
